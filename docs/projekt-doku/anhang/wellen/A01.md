## Offen

- `braces` (Dev-Abhängigkeit) nur mit `npm audit fix --force` (Breaking) behebbar – auf
  Tailwind/ESLint-Update warten.
- `Cross-Origin-Opener-Policy: same-origin` trennt Popup-Beziehungen zu fremden Origins. Derzeit
  nutzt die Website keine OAuth-/Zahlungs-Popups; falls später (z. B. Login-Popups) nötig,
  Pfad in der Ausnahmeliste ergänzen.
- Dev-Audit (`npm audit` ohne `--omit=dev`) meldet weiterhin 5 High (alle `braces`-Pfad).
- `src/components/Referenzkarte/map.js` ist toter Code (kein Importeur, DE-Standorte) – löschen,
  sobald ein Paket die Referenzkarte-Komponenten besitzt; dann auch `public/Images/leaflet/`
  behalten oder entfernen, je nachdem, ob eine andere Karte Bild-Marker braucht.
- Zu `.vtt`: derzeit liegt keine `.vtt`-Datei unter `public/`; die Cache-Regel greift, sobald
  Untertitel dazukommen (Dateinamen dann mit Hash versionieren, weil immutable).
