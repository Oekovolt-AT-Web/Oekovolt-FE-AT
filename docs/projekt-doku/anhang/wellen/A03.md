## Abweichungen vom Plan (begründet)

- **Zeile c ohne CallStatus.js:** `CallStatus` ist ein Sekunden-Countdown mit `animate-ping`; der Auftrag verlangt
  „kein Countdown-Ticker, kein Blinken“. Deshalb nutzt KostenDesWartens die Phasenlogik (`callPhase`, `FOERDERCALL`)
  aus `src/lib/foerdercall.js` direkt und schreibt je Phase einen Satz. Wird CallStatus später eine ruhige Variante
  (z. B. Prop `kompakt`) bekommen, kann sie hier eingesetzt werden.
- **Kundennamen:** Ohne `freigabe.name` keine Namen und kein Link auf die Projektseite (Orchestrator-Hinweis b, A02-Regel
  in hero.js). Der Plan sah ProjektKarte mit Name und Link vor – das gilt jetzt nur mit Namensfreigabe.
- **Rechtsform-Hinweis:** Für Einzelunternehmen/Personengesellschaften rechnet die Komponente mit einem wählbaren
  ESt-Tarifsatz (Standard 48 %) und weist „abhängig vom Grenzsteuersatz“ aus; der Plan nannte keinen Satz.
