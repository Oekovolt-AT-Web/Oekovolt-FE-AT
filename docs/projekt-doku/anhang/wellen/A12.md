## Übergabe (fremde Dateien)

1. **`src/app/layout.js` (D07/E03):** Im `<head>` `import { COOKIE_KOPF_SKRIPT } from "@/components/Cookies/cookiecomponent"` und `<script dangerouslySetInnerHTML={{ __html: COOKIE_KOPF_SKRIPT }} />` als erstes Kind einfügen; danach in `cookiecomponent.js` die Zeile `{!forceShow && <script … COOKIE_KOPF_SKRIPT … />}` entfernen. Bei einer künftigen CSP mit `script-src` braucht das Inline-Skript eine Nonce bzw. einen Hash.
2. **A10 – `src/components/RechnerGewerbe/GewerbePVRechner.js`:** `window.dispatchEvent(new CustomEvent("ov-rechner-angebot", { detail: { url } }))` bei jeder Änderung der Werte senden (nicht nur beim Mount). `url` als `/angebot?…` (relativ) – andere Pfade/Herkünfte verwirft die Leiste.
3. **Solarrechner-Range-Inputs (A10 bzw. Besitzer `src/components/Solarrechner/Rechner.js`, `src/components/Rechner/bausteine.js`):** Trefferfläche ≥ 44 px. Global in `.ov-range` nicht umsetzbar, ohne die Abstände (`mt-3`, `my-4` …) aller 19 Rechner zu verschieben (unlayered CSS schlägt die Utilities). Vorschlag je Komponente: Input in einen `py-[18px]`-Wrapper mit `-my-[18px]` legen oder Höhe 44 px + Hintergrund `center / 100% 8px no-repeat` setzen und die Abstände dort angleichen. Der Daumen hat 26 px (WCAG 2.5.8 AA erfüllt).
4. **Kontrast-Altbestand (E10):** `scripts/kontrast-klassen.test.mjs` meldet weiterhin 366 Warnungen in fremden Dateien; A12-Dateien sind bereinigt (dekorative Flächen `bg-ov-500/30` u. ä. bleiben).
5. **`src/components/Home/BackToTop.js`:** hat keine eigene Klasse; globals.css greift über `button[aria-label="Nach oben"]`. Wer das Label ändert, muss die Regeln in globals.css mitziehen (besser: Klasse `ov-nach-oben` ergänzen).

6. **Besitzer `src/app/rechner/gewerbe-pv/page.js` (A10):** Seitenkopf ohne `actions`; der JSX-Lead („Was bringt Ihr Hallendach?“ + Absatz) und 5 Punkte schieben das Werkzeug mobil auf ca. 710 px. Vorschlag: `actions={[{ label: "Jetzt rechnen", href: "#rechner" }]}` (Anker auf das Werkzeug) oder Lead als String übergeben, dann greift die mobile Kürzung von PageHero.
